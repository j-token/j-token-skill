# Context Audit

Claude Code 설정을 감사해서 컨텍스트를 낭비하거나 속도를 늦추는 모든 것을 찾고, 더 간결한 설정을 제안한다. **사용자의 OK 전에는 아무 파일도 수정하지 않는다.**

## 0. 기준선 확보

- 사용자가 `/context all` 출력을 붙여넣었으면 그것을 기준선(before)으로 쓴다.
- 없으면 먼저 요청한다: "`/context all`을 실행하고 출력 전체를 붙여넣어 주세요." 출력 없이도 진행은 하되, 토큰 수치는 추정치임을 명시한다.

## 1. CLAUDE.md 감사

이 프로젝트에 로드되는 모든 메모리 파일을 찾는다. 사용자 수준 포함.

- `~/.claude/CLAUDE.md` (사용자 수준)
- 프로젝트 루트와 상위 디렉터리의 `CLAUDE.md`, `CLAUDE.local.md`
- 하위 디렉터리의 `CLAUDE.md`
- `@import`로 끌어오는 파일
- 기존 `.claude/rules/*.md`

각 파일에 대해 `wc -l`로 줄 수를 보여주고, 다음을 플래그한다:

- **모호함**: "깔끔하게 작성", "모범 사례 따르기"처럼 행동을 바꾸지 않는 지시
- **오래됨**: 존재하지 않는 경로·스크립트·의존성, 바뀐 명령어 (실제로 확인할 것)
- **중복**: 파일 간, 혹은 Claude 기본 동작과 겹치는 내용
- **국소적**: 코드베이스 한 부분에만 해당하는 규칙 → `.claude/rules/` 이동 후보

Anthropic 문서는 파일당 200줄 미만을 권장한다. 초과 파일은 별도로 표시한다.

## 2. MCP 서버 감사

`claude mcp list`를 실행한다. 각 서버에 대해:

- 무엇을 위한 서버인지
- 이 프로젝트에서 실제로 쓰는 것이 있는지 (코드, 스크립트, CLAUDE.md, 워크플로에서 근거를 찾아 제시)
- 스코프(user / project / local)와, `/context all` 출력에 나온 해당 서버 도구들의 토큰 비중
- 판정: 유지 / 프로젝트 스코프로 축소 / 제거

## 3. 스킬·플러그인 감사

- `~/.claude/skills/`, `.claude/skills/`, 설치된 플러그인(`~/.claude/plugins/` 등)을 나열한다.
- 각 항목의 description 길이도 본다 (description은 항상 로드됨).
- 기능이 겹치는 것, 이 프로젝트에 필요 없는 것을 플래그한다.

## 4. 간결한 설정 제안

세 범주로 나눠 제안한다:

1. **자를 것**: 삭제해도 행동이 안 바뀌는 내용, 안 쓰는 MCP·스킬·플러그인
2. **다시 쓸 것**: 긴 설명을 짧고 구체적인 규칙으로 (예: "테스트 꼭 돌려라" → "커밋 전 `pnpm test --filter <pkg>` 실행")
3. **옮길 것**: 특정 경로에만 해당하는 규칙을 `.claude/rules/<주제>.md`로 옮기고 `paths:` frontmatter를 달아 일치하는 파일을 작업할 때만 로드되게 한다. 예:

```markdown
---
paths:
  - "src/api/**/*.ts"
---
- API 핸들러는 zod로 입력 검증
```

제안한 새 파일 내용은 전문으로 보여준다.

## 5. 이전/이후 테이블 → OK 대기

다음 형식으로 요약한다:

| 항목 | 이전 | 이후 | 변경 내용 |
|---|---|---|---|
| ~/.claude/CLAUDE.md | 240줄 | 80줄 | 중복 제거, 규칙 압축 |
| MCP: xxx | user 스코프 | 제거 | 이 프로젝트에서 미사용 |
| ... | | | |

`/context all` 기준선이 있으면 항목별 예상 토큰 절감량도 적는다.

그다음 **멈추고** "이대로 적용할까요? 항목별로 빼거나 고칠 것이 있으면 말씀해 주세요."라고 묻는다. 사용자의 명시적 OK 전에는 어떤 파일도 수정·삭제하지 않고, MCP 제거 명령도 실행하지 않는다.

## 6. 적용 후

- 승인된 항목만 적용한다. 삭제 대신 가능하면 백업(`*.bak` 또는 git 커밋)을 남긴다.
- 사용자에게 `/context all`을 다시 실행해 출력을 붙여넣어 달라고 하고, 기준선과 비교 테이블을 보여준다.
